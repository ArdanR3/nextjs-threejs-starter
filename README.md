# Next.js + Three.js Starter

A minimal starter template that combines Next.js (TypeScript) with Three.js to quickly build interactive 3D web applications.

## Features

- Next.js with TypeScript support
- Three.js scene with a rotating cube
- Ready-to-run development server (`npm run dev`)

## Getting Started

```bash
git clone https://github.com/ArdanR3/nextjs-threejs-starter.git
cd nextjs-threejs-starter
npm install
npm run dev
```
